# BCom Salary Prediction

This project predicts salary based on years of experience using Machine Learning.

**Done by:** B.Com Student
**Tool Used:** Google Colab (Python)

### Dataset
- 60 Jobs Data
- Columns: Years of Experience, Salary

### What I Did
1. Collected 60 jobs data
2. Cleaned the data
3. Created Scatter Plot - Experience vs Salary
4. Created Line Graph - Salary Growth
5. Created Bar Chart - Average Salary by Experience Level
6. Created Pie Chart - Job Distribution
7. Trained Linear Regression Model
8. Predicted Salary for Fresher and Experienced persons

### Conclusion
From the analysis of 60 jobs data, it is clear that salary increases with years of experience. Freshers get low salary, but after gaining experience, salary grows steadily. Experience is the most important factor for salary growth in B.Com jobs.
